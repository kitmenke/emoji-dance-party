# 🍌 Emoji Dance Party

A fun, interactive BPM rhythm visualizer built with Next.js and D3.js. Tap the beat, and watch your favorite fruit and vegetable emojis dance in sync!

## Features

- **BPM Detection** – Tap spacebar to the beat; BPM is calculated from your tap intervals
- **Emoji Selection** – Choose from 16 different fruit & vegetable emojis
- **Variable Dancers** – Add or remove dancing emojis with arrow keys
- **Scattered Mode** – When you have 6+ dancers, they spread across the screen with random sizes
- **Synced Animation** – All emojis dance perfectly in sync with a double-bounce pattern

## Controls

| Key | Action |
|-----|--------|
| `SPACE` | Tap the beat |
| `↑` | Add 2 more dancers |
| `↓` | Remove 2 dancers |
| `←` / `→` | Change emoji |

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to start the party!

## Tech Stack

- **Next.js 16** – React framework
- **D3.js** – Data visualization library
- **Tailwind CSS 4** – Styling
- **TypeScript** – Type safety
